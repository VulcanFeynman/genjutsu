# Genjutsu

**Your photo. A new starring role in trending clips.**

🌐 Website: [Genjutsu](https://genjutsu.tv/)

## About

Genjutsu is a web-based AI video studio focused on motion transfer and template remixes. You start from a performance you already like—runway walks, dances, music moments or object shots—then add your own reference photos so the scene gets a new cast, outfit or subject while the source motion and camera remain the guide.

## Features

- Video motion transfer using reference images
- Object, character and outfit replacement
- 480p, 720p and 1080p output options
- Source-guided duration up to about 30 seconds
- Reusable source video and ordered image workflows
- Labeled source vs remix comparisons

Visit [https://genjutsu.tv/](https://genjutsu.tv/) to try Genjutsu in your browser — no install required.
